{% trans "Accessibility" %}

{% trans "Updated 24 August 2026" %}

{% blocktrans trimmed %}This accessibility statement applies to the IPAD Indonesian Prehistoric Archaeology Database (“IPAD”, “we”, “us”) website. After this first mention we usually say “IPAD”.{% endblocktrans %}

{% trans "This website is run by IPAD. We want as many people as possible to be able to use this website. For example, that means you should be able to:" %}

  • {% trans "change colours, contrast levels, and fonts using your browser or device settings" %}
  • {% trans "zoom in up to 300% without the text spilling off the screen on most pages" %}
  • {% trans "navigate most of the website using just a keyboard" %}
  • {% trans "navigate most of the website using speech recognition software" %}
  • {% trans "listen to most of the website using a screen reader (including recent versions of JAWS, NVDA, and VoiceOver)" %}

{% trans "We have also tried to keep the website text as simple as possible to understand." %}

{% trans "How accessible this website is" %}

{% trans "We know some parts of this website are not fully accessible:" %}

  • {% trans "maps used in search and resource views may be difficult to navigate with a keyboard alone and hard to read for users with a visual impairment" %}
  • {% trans "some map colours and contrast may not meet recommended contrast levels" %}
  • {% trans "some heritage images or archival reproductions may not have alternative text" %}
  • {% trans "parts of the Arches application interface (for example complex editors used by staff) may be harder to use with assistive technology than these information pages" %}

{% trans "Search tools that do not rely on the map remain available so that record information can be found as text." %}

{% trans "Feedback and contact information" %}

{% trans "If you need information on this website in a different format, such as large print, easy read, or another accessible file:" %}

  • {% trans "email cata@nusantaraheritage.org (plain text; this is not a mail link)" %}

{% trans "We will consider your request and get back to you." %}

{% trans "Reporting accessibility problems with this website" %}

{% trans "We are always looking to improve the accessibility of this website. If you find any problems not listed on this page, or think we are not meeting the aims described here, email cata@nusantaraheritage.org." %}

{% trans "Technical information about this website’s accessibility" %}

{% trans "IPAD aims to make this website accessible. We use the Web Content Accessibility Guidelines (WCAG) version 2.2, Level AA, as our technical reference. WCAG is an international standard; this page does not claim compliance with any particular national accessibility statute until that is confirmed." %}

{% trans "Compliance status" %}

{% trans "This website has not yet had a full independent accessibility audit for IPAD. Until that work is done, we treat the site as only partially meeting WCAG 2.2 Level AA, because of the map, image, and interface issues listed above." %}

{% trans "Non-accessible content" %}

{% trans "The content listed below is not fully accessible for the following reasons." %}

  • {% trans "Online maps: keyboard access, colour, and contrast can fail recommended criteria. Essential record information is also available through text search." %}
  • {% trans "Images: some photographs and figures may lack alternative text." %}
  • {% trans "Staff-only editors and workflows in Arches may not yet meet the same standard as these public information pages." %}

{% trans "What we are doing to improve accessibility" %}

{% trans "It is IPAD’s intention to improve accessibility over time. We will review this statement when we complete testing or when we make significant changes to the public interface." %}

{% trans "Preparation of this accessibility statement" %}

{% trans "This statement was prepared on 24 August 2026 for the IPAD public Arches site. It was adapted from the structure of comparable heritage-database accessibility statements. It has not yet been validated by an external accessibility agency for this IPAD installation." %}
